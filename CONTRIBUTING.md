# Contributing

CommandAGI connects agents to real computers, devices and environments. Keep this repository a
small, understandable implementation of the capability described in its README.

Open an issue or pull request on this repository. Include the behavior being changed, reproduction
steps, commands you ran, and the relevant board/OS/runtime versions. Keep credentials and personal
account data out of source, screenshots and logs. New hardware support must document wiring and
which behavior was actually tested; simulation or compilation alone does not verify hardware.

Run the checks in `.github/workflows/validate.yml` before submitting a change. Live tests require
your own account and, where applicable, supervised hardware. Describe any live tests you could not
run. Contributions are licensed under the repository's MIT license.
